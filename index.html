Règles de calcul

  • Urgent : échéance dans 2 jours ou moins (ou dépassée), ou priorité P1 / P2, ou Bloquant = Oui.
  • Important : Impact client = Oui, ou Visible manager = Oui, ou priorité P1 / P2, ou famille Incidents, Problem, Fournisseurs ou Sécurité / CVE.
  1. Faire maintenant : urgent et important.
  2. Planifier : important, pas urgent.
  3. Déléguer / regrouper : urgent, pas important.
  4. Reporter / abandonner : ni urgent ni important.

Les actions au statut « Fait » sortent de la matrice. Les colonnes Urgent, Important et Quadrant du fichier Excel sont ignorées : tout est recalculé ici, à la date du jour.

Changement de statut : menu sur chaque carte, bouton rond pour marquer « Fait », ou glisser-déposer entre les colonnes du Kanban. Sous Chrome ou Edge (ordinateur), le changement est écrit aussitôt dans la colonne Statut du fichier Excel, sans toucher au reste du classeur ; fermez le fichier dans Excel pendant ce temps.

Confidentialité : le fichier est lu et modifié uniquement sur votre poste, dans votre navigateur. Aucune donnée n'est envoyée sur un serveur ; elles sont seulement mémorisées dans le stockage local de ce navigateur, jusqu'à « Effacer les données ».
